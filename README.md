# MyBabes Clone

This project is a functional clone of mybabes.ai, featuring a Next.js frontend, PostgreSQL database with Prisma ORM, and integrated chat capabilities.

## Status
- Project initialized.
- Dependencies defined in package.json.
- Build environment requires local installation of node_modules.

## Next Steps
1. Run 'npm install' in your local environment.
2. Configure DATABASE_URL in .env.
3. Run 'npx prisma db push' to initialize the database.
4. Start the development server with 'npm run dev'.
